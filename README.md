# CAPS_OFF-submission
A web platform to manage students, track performance, and simplify academic administration through an intuitive dashboard.
---
##Live demo
https://frabjous-frangipane-37c4c3.netlify.app

## Problem Statement
In most colleges, academic tools are scattered across many platforms.  
Students and faculty must open multiple portals to check attendance, courses, assignments, announcements, and internships.

This creates several problems:

• Too many websites to manage  
• Important updates get missed  
• Poor user experience  
• No single place for academic resources  
• Time wasted switching between systems  

There is a clear need for a **single unified academic portal**.
---

## Solution
The platform provides:
-Role-based Login
- Dashboard overview
- Student management interface
- Quick navigation cards
- Clean and responsive UI
The system is designed to support authentication, data storage, and real-time academic services as the next phase of development.
